# Expense Tracker Web Application

## Overview
The Expense Tracker application is a simple, user-friendly platform for tracking income and expenses. It features interactive tools to add transactions, view transaction lists, generate insightful reports, and contact support. Built with Materialize CSS for a responsive and visually appealing design, this web app is perfect for managing personal finances.

---

## Features

1. **Add Transactions**
   - Quickly add new income or expense entries to keep your records updated.
   - Accessible through the "Add Transaction" card on the homepage.

2. **View Transactions**
   - Review all past transactions in a well-organized list.
   - Includes options to filter or remove transactions.
   - Accessible via the "View Transactions" card.

3. **Reports & Insights**
   - Analyze spending trends and income with interactive graphs.
   - Generate custom reports by selecting date ranges.
   - Navigate to this section through the "Reports & Insights" card.

4. **Contact Us**
   - Reach out for assistance or inquiries through the contact page.
   - Accessible through the "Contact Us" card.

---

## How to Use

### 1. Homepage
- **Purpose**: Provides quick navigation to all main sections.
- **Components**:
  - Horizontal cards with images, descriptions, and buttons for navigation.
  - Click on the appropriate card to proceed.

### 2. Adding a Transaction
- **Steps**:
  - Click on the "Add Transaction" card or navigate to `form.html`.
  - Fill out the required fields, such as amount, date, and category.
  - Submit the form to save the transaction.

### 3. Viewing Transactions
- **Steps**:
  - Click on the "View Transactions" card or navigate to `list.html`.
  - View a list of all recorded transactions.
  - Use provided options to filter or remove entries.

### 4. Generating Reports
- **Steps**:
  - Click on the "Reports & Insights" card or navigate to `reports.html`.
  - Select a date range to generate a visual report of transactions.
  - Review insights presented in interactive charts.

### 5. Contacting Support
- **Steps**:
  - Click on the "Contact Us" card or navigate to `contact.html`.
  - Fill out the form to submit your query or feedback.

## Setup Instructions

1. **Download the Files**
   - Clone or download the project files to your local machine.

2. **File Structure**
   - `index.html`: Homepage.
   - `form.html`: Add Transaction page.
   - `list.html`: Transaction List page.
   - `reports.html`: Reports & Insights page.
   - `contact.html`: Contact Us page.
   - `styles.css`: Contains global styles for the web app.
   - Images: Ensure the following images are in the project directory:
     - `Add Transaction.PNG`
     - `Transaction List.PNG`
     - `Insights.PNG`
     - `Contact.PNG`

3. **Run Locally**
   - Open `index.html` in a web browser to start using the application.
